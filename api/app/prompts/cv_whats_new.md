A person is updating their CV. They wrote, in their own words (Arabic or English), what is new
since their last CV. Sort what they said into the parts of a CV. Copy names as they wrote them;
never add a project, skill, certificate, job or activity they did not mention.

- projects: each new project. name (as written), what (what it does or what they did, in their
  own words), tools (the tools they named for it), role (their part, if said), start and end
  (if said), url (if given)
- jobs: each new job or internship: company, title, what, start, end
- skills: each new skill, tool or technology they say they learned or use
- certs: each certificate, with its date if they gave one
- langs: each language they now speak, with its level if given
- activities: each club, membership, volunteering or award, with its role if given

Return JSON only, with exactly these keys; an empty list where they said nothing for a part.
